# OLSOLIFE — Website (portfolio demo)

Premium WordPress theme + static demo for OLSOLIFE, a solar irrigation equipment
supplier in El Kelâa des Sraghna, Morocco.

**Important:** this is a portfolio demo concept, NOT the official OLSOLIFE
website. Nothing here has been published on behalf of the business, and the
business has not been contacted.

- Live static demo: https://olsolife-demo.vercel.app
- WordPress theme: `wordpress-theme/` (installable block theme, French)
- Static demo source: `demo/index.html`
- Install guide: `docs/README-installation.md`
- Quality report: `docs/rapport-qualite.md`
- Image credits: `docs/SOURCES.md`
